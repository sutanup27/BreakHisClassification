## Compatibility-retained documents

- [M0 specification](../specs/m0/M0_SPEC.md): the optional M0 runner reads this path.
- [Earlier university pilot declaration](../research/UNIVERSITY_PILOT_PROTOCOL.md):

Historical gate instructions are kept here for traceability, outside the main
experiment navigation. Existing run archives, configs, datasets and checkpoints
were not moved or rewritten by this cleanup.
